# 🏆 Productivity Prediction Based on Digital Lifestyle

## 📌 Project Overview
This project analyzes how digital habits such as social media usage, screen time, sleep patterns, and stress levels impact an individual's productivity.

A machine learning model is used to predict a user's productivity score based on behavioral and lifestyle inputs. The application also provides personalized feedback and actionable suggestions to help improve productivity and maintain a healthy digital lifestyle.

---

## 🚀 Features
- Predicts productivity score based on digital habits
- Accepts inputs like social media usage, sleep, stress, and work patterns
- Provides personalized feedback and improvement suggestions
- Interactive web application built using Streamlit
- Focuses on digital wellbeing and work-life balance

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Streamlit  

---

## 📊 How It Works
1. User enters lifestyle and digital habit data  
2. Data is preprocessed and scaled  
3. Machine learning model predicts productivity score  
4. System generates personalized feedback and suggestions
